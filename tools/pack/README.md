# Prelims Pack (prelims.html)
build_pk.py builds pk/pack.json, encrypted pk/files/*.bin, free pk/free/*.pdf and 3-page samples. Needs codes.json {"pack":"G12-XXXXXX"} (private, owner has it — never commit), source PDFs and parsed tests. To add a volume or test, add it to VOLS/TESTS and rebuild with the SAME code.
